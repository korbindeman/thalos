# Thalos terrain-diffusion content (NTR-X2a)

Consumed by `thalos_terrain::DiffusionSurface` when `THALOS_TERRAIN=diffusion`
(the `BodySurfaceRegistry` / `world_map` toggle).

| File | What | In git? |
|---|---|---|
| `thalos_chart_elev.f32/.json` | Global equirect coarse chart, 869×434 @ 23.04 km/px (equator-exact), ocean clamped to 0 | yes |
| `thalos_site_detail_6144_90m.f32/.json` | 553 km native-resolution (90 m) window centred on the spaceport site (lat 7.6, lon 178) | yes — payload via Git LFS |

## Download

A normal clone downloads the detail payload automatically when Git LFS is
installed. For a clone made without LFS, or one made with smudging disabled:

```bash
just terrain-assets
```

That command installs the repository-local LFS filters, downloads only the
learned terrain payloads, and verifies the LFS object store. The payload's LFS
object id is its SHA-256, so it must equal `sha256_le_f32` in the JSON sidecar.
For the current 6144² window both are
`60828b673d43b8badc0747861f59d9058a59fa7d49487046ff61b4fbc03c3482`.

Training datasets, checkpoints, optimizer state, and `terrain_runs/` remain
ignored. They are not needed to render the checked-in learned terrain.

Regeneration is deterministic (seed-pinned, byte-identical per NTR-FT-0) and is
only needed when intentionally replacing the published payload:

```bash
# 1. Canonical macro conditioning rasters (Thalos's own continents/climate):
cargo run -p thalos_terrain --release --example export_thalos_macro

# 2. In the terrain-diffusion checkout (see its FT0_NOTES.md for the env):
python thalos_export.py --seed 1337 \
  --condition-dir <thalos>/target/thalos_macro \
  --site-lon 178 --site-lat 7.6 --detail-side 6144
# 3. Copy thalos_out/thalos_chart_elev.* and thalos_out/thalos_site_detail_*
#    into this directory.
```

`thalos_chart_elev.json` must preserve the
`conditioning_generator_version` written by `target/thalos_macro/thalos_macro.json`.
The runtime and `just map` compare it with the current terrain generator and
warn when learned macro relief is structurally stale. The installed chart is
currently generator 28; generator 33 conditioning is ready for the next bake.

The chart is generated by the released terrain-diffusion pipeline
(`xandergos/terrain-diffusion-90m`, MIT) **conditioned on Thalos's canonical
macro terrain** via the pipeline's custom-conditioning import — the continents
are the game's own geography in the model's coastline/relief language. Without
the detail window the surface still works planet-wide (chart + conditioned
analytic bands); the window adds true 90 m model relief around the spaceport.

Beware the pipeline's mixed axis orders: `pipe.get(i1, j1, ...)` is
**row-first** — passing (x, y) exports a window ~600 km away (found 2026-07-24;
`thalos_export.py` carries the fix + comment).
