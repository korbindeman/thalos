# Dismissed findings

Findings the retired expert-review harness ruled `by-design` or `wrong`, with
citations. Read before filing a defect in a previously reviewed slice.

Without this file the routine re-discovers the same twenty things every week and
you stop reading it by week three. Appending is not bookkeeping — it is the
mechanism.

**Rows are permanent.** If a dismissal is later shown to be mistaken, do not
delete the row: strike it and add a line saying what changed. Deleting it just
means it gets re-filed.

**`by-design` is not agreement.** It means a written decision covers the case. If
you want to *revisit* one, that is a `steer` conversation and a superseding ADR —
not a review finding.
