# Backlog

The queue that answers **"what's next?"** — and the **only** status authority in
the repo. The sprint plans ([neural_terrain_renderer.md](roadmap/neural_terrain_renderer.md)
`ntr`, [architecture_cleanup.md](roadmap/architecture_cleanup.md) `clean`,
[graphics_fidelity.md](roadmap/graphics_fidelity.md) `gfx`) hold strategy and
rationale; they carry no parallel checkboxes to keep in sync. Driven by the
`steer` skill (`.claude/skills/steer/SKILL.md`).

**What gets a row:** work that **outlives the current session** — multi-step
items, anything handed back to the user, anything deliberately deferred. Work you
find and finish in the same change doesn't need one; the commit is the record.
Don't let a row become a second place to write the design.

**Status:** `next` (ready) · `wip` · `verify` · `blocked` (blocker in **Deps**) ·
`done` (date in Notes) · `later` (not yet pickable).

`verify` is the load-bearing one: **landed compile-clean but not runtime-verified.**
Agents can't run the game, so the row names what closes it — a headless probe
(`just screenshot` / `just preview` / `just ui-preview`, agent-servable) or a user
play session. Never `done` on "it compiles".

**IDs:** reuse a plan doc's own ID (`NTR-M*`, `CL-A`…`CL-G`, `F1`–`F9`, `W*`,
`TM*`, `C1`) when the item has one; otherwise mint `BL-YYYYMMDDTHHMMSSZ-slug`
from `date -u '+%Y%m%dT%H%M%SZ'`. **Never allocate the next `BL-n`** — parallel
branches collide, and these IDs are cited from Rust source
(ADR-20260722T170714Z). `BL-1`–`BL-40` are frozen legacy IDs. Mark `done`, don't
delete; never renumber.

**Refs:** `ntr §N` · `clean §N` · `gfx §N` = the roadmap docs ·
`ADR-YYYYMMDDTHHMMSSZ-slug` = adr/ · `INC-YYYYMMDDTHHMMSSZ-slug` = incidents/
(plus frozen legacy `INC-NNNN`) · other docs by filename.
