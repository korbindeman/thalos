# Constant boundary survival drew tectonic rings

## Symptom

The first grown-plate terrain map replaced Voronoi sectors with curved contacts,
but some land ranges still read as constant-width half-rings and long painted
strokes. Large plate interiors were nearly featureless by comparison.

## Mechanism

The conspicuous hook survived a zero-microplate comparison almost unchanged: it
was a legitimate major-plate contact, not a compact microplate. The terrain
response was the defect. One broad noise value controlled survival along too
much of each contact, while a fixed falloff gave every surviving kilometre the
same corridor width. Removing the former independent orogeny field had also
erased subdued ranges inherited from older plate systems.

## Fix and recurrence tell

Keep the continuous process-labelled contact for diffusion conditioning, but
vary its corridor width and resolve visible preservation at a shorter regional
scale so old contacts survive as separated massifs. Blend low-amplitude
inherited terranes into plate interiors. The regression test requires both
quiet and strong texels along convergent contacts; an atlas where every
convergent contact becomes one equally bright ridge has recurred.
