# Agent scratchpad

Disposable visual iterations belong here, normally under `screenshots/`.
`just compare` writes its A/B and N-way matrices here automatically. Agents
may clear or replace these files as they work; durable conclusions belong in
the relevant documentation or incident report.

The sibling `tools/screenshots/` directory is not a scratchpad. It contains
only the latest canonical preset views written by `just screenshot <preset>`.
Machine-readable runtime traces belong in `tools/diagnostics/`.
